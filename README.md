## 📌 Огляд проєкту
**HIVanalyzer** — це програмна екосистема для моделювання та оптимізації систем вентиляції та кондиціювання повітря (ОВКПа). Проєкт поєднує методи фізичного моделювання будівель (Building Energy Modeling) та глибокого навчання з підкріпленням (Reinforcement Learning) для створення енергоефективних систем підтримки мікроклімату.

Проєкт розроблений як частина дипломної роботи, що фокусується на створенні "Цифрового двійника" приміщення для автоматизованого підбору та керування рекуператорами.

---

## ✨ Основні можливості

### 🏗️ Параметричне моделювання (IDF Bridge)
- Автоматична генерація геометрії приміщень (включаючи складні L-подібні форми).
- Динамічне створення IDF-файлів для рушія **EnergyPlus**.
- Гнучке налаштування матеріалів стін, вікон та інженерного обладнання.

### 🌡️ Фізична симуляція (EnergyPlus Engine)
- Точний розрахунок термодинаміки приміщення з урахуваний теплової інерції.
- Симуляція динаміки CO₂ та специфічних забруднювачів (VOC, дрібнодисперсний пил).
- Інтеграція систем керування EMS (Energy Management System) для плавного регулювання вентиляції.

### 🤖 Штучний інтелект та Оптимізація
- **RL Agent:** Навчання агентів для балансування між якістю повітря та споживанням енергії.
- **ML Surrogate Models:** Використання нейромереж для швидкого прогнозування стану середовища.
- **Batch Processing:** Генерація масивних синтетичних датасетів для подальшого навчання моделей.

### 📊 Інтерактивний інтерфейс (Streamlit)
- Візуалізація архітектури приміщення.
- Моніторинг результатів симуляції в реальному часі.
- AI Lab для налаштування та тренування моделей безпосередньо з браузера.

## 🛠️ Технологічний стек
- **Мова програмування:** Python 3.10+
- **Фізичний рушій:** EnergyPlus 25.2.0
- **Frontend/Dashboard:** Streamlit
- **Machine Learning:** PyTorch, Scikit-learn, Stable Baselines3
- **Data Processing:** Pandas, NumPy, Plotly

## 📁 Структура репозиторію
```text
HIVanalyzer/
├── ai/                 # Модулі ШІ: RL-агенти, середовища навчання, сурогатні моделі
├── core/               # Ядро системи: константи, логіка розрахунків
├── data/               # Конфігураційні файли та збережені стани
├── simulation/         # Інтеграція з EnergyPlus, генерація IDF, валідація
├── ui/                 # Компоненти інтерфейсу Streamlit (вкладки, дизайн)
├── weather/            # Файли метеоданих (.epw)
├── main.py             # Точка входу в застосунок
└── requirements.txt    # Залежності проєкту
```

## 🚀 Швидкий старт

### 1. Попередні вимоги
Переконайтеся, що у вас встановлено:
- Python 3.10 або вище.
- [EnergyPlus 25.2.0](https://energyplus.net/downloads) (має бути доданий до системних змінних або вказаний шлях у налаштуваннях).

### 2. Встановлення залежностей
```bash
git clone https://github.com/Hrankivski/HIVanalyzer.git
cd HIVanalyzer
pip install -r requirements.txt
```

### 3. Запуск застосунку
```bash
streamlit run main.py
```
